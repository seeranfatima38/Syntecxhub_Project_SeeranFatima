# Maze Solver using A* Search

## Description
This project implements the A* search algorithm to solve a maze and find the shortest path.

## Features
- Uses A* Search Algorithm
- Supports Manhattan/Euclidean heuristic
- Finds shortest path
- Handles unreachable cases

## How to Run
1. Open the file in Python
2. Run: python maze_solver.py
